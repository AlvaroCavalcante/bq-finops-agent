# Agent Spec — bq-finops-agent

## Overview

One-shot BigQuery SQL optimizer agent built with ADK. Receives a SQL query and optional context instructions, rewrites the query following Google BigQuery best practices to reduce bytes processed, measures baseline vs optimized cost (dry-run with automatic live fallback), and returns a structured optimization report.

## Example Use Cases

1. Analyst pastes a heavy SELECT → receives optimized SQL, bytes saved, USD estimate.
2. Engineering pipeline passes SQL from audit logs → same agent via API/CLI/A2A.

## Tools Required

See README and `app/tools/` for full list.

## Constraints & Safety Rules

- SELECT / WITH / INSERT / MERGE (dry-run). Live never runs INSERT/MERGE.
- UPDATE / DELETE / DDL rejected
- maximum_bytes_billed on live runs
- Never add LIMIT/TABLESAMPLE/APPROX_* unless in input
- Preserve column names and SQL comments

## Success Criteria

- baseline_measured, schema preserved; UPDATE/DELETE/DDL rejected; INSERT/MERGE dry-run only; live only for SELECT when clustering or dry-run cannot estimate bytes
